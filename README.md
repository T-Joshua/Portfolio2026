# Joshua Taiwo Portfolio

A responsive personal portfolio website for Joshua Taiwo, a full-stack software engineer and web development instructor. The site showcases technical skills, featured projects, work experience, and a contact form for project inquiries and collaborations.

## Overview

This portfolio is designed to present Joshua's experience in:

- Full-stack web development
- Backend engineering with Python and Flask
- Frontend development with HTML, CSS, JavaScript, and Tailwind CSS
- Teaching and mentoring in technology and frontend development

## Features

- Modern dark-themed landing page
- About section with professional overview
- Skills / tech stack section
- Project gallery with modal detail views
- Career timeline and experience highlights
- Contact section with email and WhatsApp link
- Contact form UI for website visitors

## Tech Stack

- HTML5
- Tailwind CSS
- JavaScript
- Python (backend contact handling)
- Flask (server-side contact API)

## Local Preview

To preview the frontend locally:

```bash
cd frontend
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
